# AI Director Station (AI 导演工作站)

## 🌟 核心理念与亮点 (Core Philosophy & Highlights)

### 1. 叙事与情感至上，而非单纯的技术堆砌
市面上的 AI 视频工具往往将重心放在追求类似电影感的画面素质（如光影细节、皮肤肌理）上，而 **AI Director** 则将重心回归创作的本质——**立意、叙事切入与情感温度**。我们提供的是高度灵活的可定制性，让 AI 真正服务于创作者的表达，而非让创作者受制于 AI 的随机生成。

### 2. 深度定制的 API 级控制 vs. 传统的“提示词暴力堆叠”
大部份工作流工具仅仅是把重心放在流程连接上，通过“提示词暴力堆叠”来试图控制模型。而 AI Director 在上游（如分镜表生成阶段）就已经针对视频厂商的底层 API 进行了深度结构优化。
* **参数化运镜**：我们将运镜方向、速度等维度从提示词中剥离，在下游生成视频时直接映射为对应的 API 参数构建请求。这不仅极大地释放了提示词的空间，还让提示词能够真正回归到描述“叙事、立意、情感温度和美术”的本质上。
* **颗粒度细腻的控制**：通过 API 本身丰富的结构化字段，不仅能够打开更广阔的创作灵感，更实现了传统自然语言提示词无法企及的精准控制。

### 3. 拒绝“投骰子”，图文双轨独立传递
目前 ChatGPT 等工具制作的故事板质量已经无可挑剔。但传统做法中，如果直接将故事板图片扔给视觉模型，视频模型对图片中嵌有文字的处理权重普遍偏低，导致结果不可控。
AI Director 在流程中**严格将“文字”与“图像”在 API 层面独立拆分传递**。我们拒绝盲目的随机性，确保故事板的每一个视觉设定和文本意图都能被模型精准捕获。

### 4. 摒弃黑盒：工业化、透明、可控的持续生产能力
* **非全自动的 Human-in-the-Loop**：全自动 AI 往往意味着输出不可控和试错成本的徒增。AI Director 摒弃了 AI 的黑盒逻辑，对于 AI 返回的每一个结果，创作者都可以**自由编辑、修改、甚至推翻重来**，然后再将其递交给下一步。
* **高稳定的结构化通信**：全流程的输入、传递和输出均维护独立的结构化 JSON。每一个 AI 交互环节均使用特定协议进行串联，字段规整、严格对应。这对底层模型而言意味着极高的稳定性，对系统架构而言则具备极强的灵活性和可拓展性。
* **角色锚点贯穿全局**：在早期的剧本设定步骤中，系统会率先生成并固化「角色档案」（Character Profile）。该档案将作为贯穿下游所有生成流程的绝对锚点，保证跨镜头的角色一致性。

### 5. 面向创作者的“极简表单化”工程设计（最小化学习成本）
* **原生复杂 API 的降维表单化**：这个 Agent 最大的意义在于，**它将大模型底层 API 中那些极度复杂、需要编程门槛的原生功能（如角色注册、面部权重、轨迹控制等），全部降维成最直观的“表单选项”**。
* **零门槛上手**：创作者不是程序员！系统摒弃了故弄玄虚的“假专业”复杂面板，将学习成本降至最低。这让创作者能够将工作和思考的中心全部倾注于内容的叙事、立意和美术这些最核心的价值上，而无需在复杂的工作流配置上耗费心神。
* **工程级健壮性**：系统实现了模型状态与前端 WebUI 的深度集成（通过 SQLite 实时监控），并为各环节配备了完善的错误处理与兜底回退（Fallback）方案。且系统架构不受制于单一模型厂商的约束，可自由无缝切换底层能力。

## 商业模式与应用场景
AI Director 专为需要应对批量场景，同时又必须保证高质量输出的工业化生产而设计。

1. **SaaS 服务模式** 
   为广大中小型内容团队、独立创作者提供开箱即用、已部署好的 AI 导演工作站，大幅降低高质量视频内容的制作门槛。
2. **批量 IP 内容代工制作** 
   作为承接方，为拥有庞大 IP 矩阵的企业提供批量内容产出服务。
   * **场景痛点解决**：以 Pop Mart（泡泡玛特）等潮玩企业为例，当线下门店和传统渠道面临增长瓶颈时，公司沉淀的海量 IP 资产急需寻求**多模态的变现能力**（如动态短片、剧情动画等）。AI Director 的工业化一致性完美契合了这种 IP 批量衍生的诉求。
3. **MCN 赋能模式** 
   将该 Agent 体系作为核心武器赋能 MCN 旗下签约的创作者。其极低的学习成本使得这套工作流可以迅速在大量创作者中大面积铺开，实现低成本、高质量的产能爆发。

## 🎬 生产工作流 (Production Workflow)

AI Director 采用人机协同（Human-in-the-Loop）的交互模式，将复杂的 AI 视频生成拆解为 7 个直观、可控的步骤。在每一个关键节点，用户都可以进行微调和把控，从而保障最终成片的高质量输出。

### Step 1: 剧本大纲设定
在此阶段，只需输入项目背景、灵感和期待的艺术风格。AI 导演会自动调用 LLM 为你构思整个故事的主线和镜头走向。
![剧本大纲设定](./sources/Step1%20画面:大纲设定.png)

### Step 1.1: 角色设计与注册
在正式进入分镜前，详细定义出场人物（如 J1、J2）。系统会自动将角色的外观、服装等特征注册到 Kling AI 的主体库中，以确保后续所有镜头中角色面部和特征的绝对一致性。
![角色设定](./sources/Step1.1%20角色设定.png)

### Step 2: 剧本分镜表 (三选一)
AI 导演会根据大纲一次性提供 3 套不同创意的分镜剧本方案。你可以对比并挑选出最符合项目预期的一套。
![分镜表三选一阶段](./sources/Step2%20分镜表三选一阶段.png)

### Step 2.1: 分镜细节微调
选定剧本后，你可以深入对每一个镜头的画面描述、机位运镜、台词和反向提示词进行精细编辑修改，直至完全满意。
![分镜编辑阶段](./sources/Step2.1%20分镜编辑阶段.png)

### Step 3: 候选分镜图 (首尾帧) 筛选
系统会为每个镜头批量生成多组候选的首尾帧图片。你可以通过视觉筛选，挑选出构图、光影最完美的画面作为视频生成的基底。
![分镜图选择](./sources/Step3%20分镜图(首尾帧)选择:确认阶段.png)

### Step 4: 视频片段生成
基于你确认的首帧/尾帧和动态提示词，系统自动调用图生视频大模型（Kling AI），生成包含复杂运镜和动作的无声视频片段。
![片段生成阶段](./sources/Step4%20片段生成阶段.png)

### Step 5: TTS 配音与 SFX 音效生成
系统为剧本中配置的台词生成高质量 TTS 语音，并同步根据镜头画面生成对应的环境 SFX 音效（如脚步声、风声、环境噪音）。
![音效与配音生成](./sources/Step5%20音效:TTS生成阶段.png)

### Step 6: 角色对口型 (Lip Sync)
*(对白镜头专属)* 系统自动调用 Lip Sync 接口，以生成的 TTS 音频驱动 Step 4 的视频，让视频中角色的嘴型动作与声音完美同步匹配。

### Step 7: 最终成片合成
一键调用 FFmpeg，系统会自动将所有审核通过的视频片段按时间轴顺序拼接，无缝混入环境音效与对白，直接输出最终的带音轨成片 (`output.mp4`)。
![成片拼接](./sources/Step7%20成片拼接.png)
